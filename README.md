# Tzeva Best (צבע בסט) — Backend

Интернет-магазин красок и товаров для покраски + услуги покраски.
Java 21, Spring Boot 3.3, PostgreSQL 16, Redis.

## Структура пакетов (`com.tzevabest`)

| Модуль         | Описание                                    |
|----------------|---------------------------------------------|
| `common`       | Кросс-функциональный код, утилиты, базовые DTO |
| `iam`          | Аутентификация и авторизация                |
| `catalog`      | Каталог товаров и категорий                 |
| `inventory`    | Складские остатки и управление наличием     |
| `cart`         | Корзина покупателя                          |
| `order`        | Оформление и управление заказами            |
| `payment`      | Платежи и интеграция с платёжными системами  |
| `shipping`     | Доставка и логистика                        |
| `service`      | Заявки на услуги покраски                   |
| `notification` | Уведомления (email, SMS, push)              |
| `admin`        | Административная панель                     |

Каждый модуль содержит подпакеты: `web`, `service`, `domain`, `repository`, `dto`, `mapper`.

Модули взаимодействуют **только** через пакеты `service` и `dto` — прямой доступ
к `repository` и `domain` чужого модуля запрещён (контролируется ArchUnit-тестом).

## Быстрый старт окружения (с нуля)

Требуется установленный **Docker** и **Docker Compose**.

```bash
make dev-up
```

Одна команда:
1. создаёт `.env` из `.env.example` (если его ещё нет);
2. поднимает инфраструктуру и ждёт, пока все сервисы станут `healthy`;
3. запускает приложение в профиле `local`.

Локальная инфраструктура (`docker-compose.yml`):

| Сервис     | Назначение                    | Адрес                                    |
|------------|-------------------------------|------------------------------------------|
| PostgreSQL | основная БД `tzevabest`       | `localhost:5432`                         |
| Redis      | кэш, сессии, корзина гостя     | `localhost:6379`                         |
| MinIO      | S3-хранилище фото (`tzevabest-media`, бакет создаётся автоматически) | API `localhost:9000`, консоль `localhost:9001` |
| Mailpit    | перехват исходящей почты       | SMTP `localhost:1025`, UI `localhost:8025` |

Данные PostgreSQL и MinIO хранятся в именованных volume и переживают перезапуск.

Полезные команды:

```bash
make infra-up      # только инфраструктура (docker compose up --wait)
make infra-down    # остановить инфраструктуру (volume сохраняются)
make infra-logs    # логи сервисов
make clean         # остановить и УДАЛИТЬ volume (данные будут потеряны)
```

> Если порты 5432/6379/9000/1025 заняты другими проектами — переопредели их
> в `.env` (`DB_PORT`, `REDIS_PORT`, `S3_PORT`, `MAIL_SMTP_PORT`).

## Команды

```bash
# Сборка
./gradlew build

# Запуск без БД (профиль nosql)
SPRING_PROFILES_ACTIVE=nosql ./gradlew bootRun

# Запуск с PostgreSQL и Redis
./gradlew bootRun

# Тесты
./gradlew test
```

## Переменные окружения

| Переменная           | Описание                | По умолчанию         |
|----------------------|-------------------------|----------------------|
| `DB_HOST`            | Хост PostgreSQL         | `localhost`          |
| `DB_PORT`            | Порт PostgreSQL         | `5432`               |
| `DB_NAME`            | Имя базы данных         | `tzevabest`          |
| `DB_USERNAME`        | Пользователь БД        | —                    |
| `DB_PASSWORD`        | Пароль БД              | —                    |
| `REDIS_HOST`         | Хост Redis              | `localhost`          |
| `REDIS_PORT`         | Порт Redis              | `6379`               |
