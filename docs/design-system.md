# Дизайн-система Tzeva Best

Снята с трёх макетов клиента (главная, каталог, панель управления). Ничего не придумано заново:
это фиксация утверждённого визуального языка в виде, пригодном для кода.

Наглядная версия с живыми образцами — артефакт «Tzeva Best Colour Card».

---

## 1. Токены

Кладутся в оба приложения без изменений. Цвет по месту в компонентах не пишется никогда, только
через переменную.

```css
:root {
  /* фирменные */
  --navy: #1b3050;        --navy-deep: #16243d;
  --brass: #b98d3e;       --brass-light: #d9b878;
  --terracotta: #d06b4a;  --sage: #9db09a;  --sage-pale: #e4eadf;

  /* поверхности и текст */
  --paper: #f8f4ec;  --paper-warm: #f2ebdd;  --surface: #ffffff;
  --ink: #1e2b3c;    --ink-soft: #5a6675;    --ink-faint: #8b94a0;
  --line: #e2d9c8;   --line-strong: #cabfa8;

  /* статусы заявки */
  --ok-fg: #2e7d51;   --ok-bg: #dcf0e4;    /* COMPLETED */
  --info-fg: #2563a8; --info-bg: #dce8f5;  /* CONTACTED */
  --warn-fg: #a97918; --warn-bg: #f8eed2;  /* RESERVED  */
  --crit-fg: #b5402f; --crit-bg: #fadfd9;  /* CANCELLED */
  /* NEW и LOST — нейтральная плашка на --paper-warm / --ink-soft */

  /* форма */
  --radius-control: 8px;  --radius-card: 12px;  --radius-pill: 999px;
  --shadow-card: 0 1px 2px rgb(30 43 60 / .05), 0 8px 24px rgb(30 43 60 / .06);

  /* шаг сетки: всё кратно 4 */
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px;
  --sp-6: 24px; --sp-8: 32px; --sp-12: 48px; --sp-16: 64px;
}
```

**Где что применяется.** Тёмно-синий несёт заголовки, основную кнопку и боковую панель админки.
Латунный — акценты, ссылки «לפרטים», рамку кнопки «צור קשר» и заливку кнопки «в заявку». Терракота и
шалфей живут только в иллюстрациях, карточках направлений и кольце фокуса: в макетах ими не окрашен
ни один интерфейсный элемент, и вводить их туда не нужно.

Семантика статусов отделена от фирменной палитры: цвет статуса не является акцентом бренда.

## 2. Гарнитуры

```css
:lang(he) { font-family: "Heebo", system-ui, sans-serif; }
:lang(ru) { font-family: "Manrope", system-ui, sans-serif; }
.display  { font-family: "Frank Ruhl Libre", Georgia, serif; }
.numeric  { font-family: "IBM Plex Mono", monospace; font-variant-numeric: tabular-nums; }
```

| Роль | Гарнитура | Где |
|---|---|---|
| Дисплейная | Frank Ruhl Libre 700 / 900 | Заголовки первого экрана и страниц, латинский подстрочник «Premium Paints» |
| Интерфейс, иврит | Heebo 400 / 500 / 700 | Весь интерфейс на ивритской локали |
| Интерфейс, кириллица | Manrope 400 / 600 / 700 | Весь интерфейс на русской локали |
| Данные | IBM Plex Mono 400 / 500 | Артикулы, номера заявок, цены, количества |

**Почему две интерфейсные гарнитуры.** Ни одна ивритская гарнитура в Google Fonts не несёт кириллицу.
Общий стек с «первым попавшимся» шрифтом даёт разнобой в высоте строчных между локалями, поэтому
семейство переключается по `:lang()`, а не задаётся один раз на `body`.

**Шкала размеров.**

| Токен | px / интерлиньяж | Назначение |
|---|---|---|
| `--fs-display` | 44 / 1.1 | Заголовок первого экрана |
| `--fs-h1` | 32 / 1.2 | Заголовок страницы |
| `--fs-h2` | 24 / 1.3 | Заголовок раздела |
| `--fs-h3` | 18 / 1.4 | Заголовок карточки |
| `--fs-body` | 16 / 1.6 | Основной текст, поля форм |
| `--fs-sm` | 14 / 1.5 | Подписи, вторая строка карточки товара |
| `--fs-xs` | 12 / 1.4 | Плашки статусов, метки таблиц |

## 3. Форма компонентов

Радиусы взяты замером с макетов: кнопки и поля 8 px, карточки 12 px, плашки статусов скруглены
полностью, цветовые кружки товара 13 px.

- **Кнопки.** Тёмно-синяя — основное действие, одна на экран. Латунная — действие в карточке товара.
  Контурная латунная — второстепенное. Приглушённая на `--paper-warm` — сброс и отмена.
- **Поля.** Фокус обводится латунью, а не системным синим: в RTL системная обводка спорит с
  направлением. Кольцо фокуса на интерактивных элементах — терракота.
- **Карточка товара.** Название на иврите, второй строкой английское, цена крупно, цветовые кружки
  доступных оттенков. Точный остаток на витрину не выводится — только градация наличия.
- **Показатель панели.** Цветная линейка сверху кодирует тему. Крупное число только там, где цифра и
  есть содержание блока.

---

## 4. RTL и две локали

1. **Только логические свойства.** `margin-inline-start`, `padding-inline-end`, `inset-inline`,
   `text-align: start`. Ни одного `left` и `right` в стилях макета.
2. **Зеркалятся стрелки, не буквы.** Иконки направления переворачиваются через
   `[dir="rtl"] .icon-chevron { transform: scaleX(-1) }`. Логотип, иконка корзины, аватар и логотипы
   брендов не зеркалятся никогда.
3. **Цифры и валюта остаются LTR.** Цена, артикул и номер заявки внутри RTL-строки оборачиваются в
   `<bdi>`, иначе знак шекеля и минус прыгают на другую сторону числа.
4. **Графики.** Ось категорий и легенда переезжают вправо, направление временного ряда — нет: время
   идёт слева направо и в иврите тоже.
5. **Таблицы админки.** Порядок колонок зеркалится, числа всегда выравниваются «к концу строки»:
   `text-align: end` плюс `tabular-nums`.

## 5. Что в макетах уже неверно

Макеты рисовались до сокращения объёма. Верстать буквально нельзя.

| Где | В макете | Должно быть | Почему |
|---|---|---|---|
| Каталог, шапка | Иконка корзины с бейджем | Счётчик заявки | Корзины нет, позиции копятся в списке заявки |
| Каталог, карточка | `הוסף לעגלה` (в корзину) | `הוסף לפנייה` (в заявку) | Оплаты на сайте нет, кнопка не должна обещать покупку |
| Каталог, шапка | Иконка личного кабинета | Убрать | Публичная регистрация закрыта, аккаунты только у персонала |
| Панель | `מכירות החודש ₪248,760` | Заявки за период | Продаж в системе нет, сделка закрывается офлайн |
| Панель | `הזמנות היום 18` | Обращения за сегодня, обоих типов | Заказы снесены миграцией V28 |
| Панель | `לקוחות חדשים 128` | Позиции в резерве | Клиентов как сущности нет; резерв менеджер смотрит ежедневно |
| Панель, график | `סיכום מכירות` в шекелях | Заявки по дням, в штуках | Денежного ряда взять неоткуда |
| Панель, диаграмма | `צבעים נמכרים ביותר` | `צבעים מבוקשים ביותר` | Считается по позициям заявок |
| Панель, таблица | `הזמנות אחרונות` с суммой | Последние обращения, без суммы | Сумма в заявке справочная, выручкой не является |
| Панель, меню | `הזמנות · לקוחות` | Заявки на товар · Заявки на покраску · Склад | Разделы приводятся к фактическим модулям |
| Каталог, карточка | Ничего про остаток | Градация наличия | Точное число наружу не отдаётся |

Итого макетов три, экранов в проекте около двадцати пяти. Остальные собираются из этой системы;
отдельного согласования каждого экрана с клиентом это не требует, но договориться об этом нужно
заранее.
